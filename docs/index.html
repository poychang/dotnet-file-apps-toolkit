READY WHEN YOU ARE.

三個步驟，開始寫。

  1. 準備環境

    安裝 VS Code 1.100+ 與 .NET SDK 10.0.100+。請確認終端機能執行 dotnet --version。

  2. 下載並安裝 VSIX

    下載最新正式版，在 VS Code 命令選擇區執行 Extensions: Install from VSIX…，選取剛下載的檔案。

  3. 建立檔案，執行！

    將上方範例儲存為 hello.cs，檢視並信任工作區，再執行 .NET File Apps: Run File。使用 Preview Tagged Comments 開啟註解預覽。

也可以使用 VS CODE CLI 
code --install-extension ./dotnet-file-apps-toolkit.vsix

在 VSIX 所在的資料夾執行此命令。手動安裝後，可從相同下載連結取得後續正式版本，再次安裝以更新。

開始之前的小提醒

所有 .cs 檔案都會出現執行按鈕嗎？

預設只辨識以 #: 指示詞或 dotnet shebang 開頭的檔案，避免把一般專案檔案誤判為單檔應用程式。也可以調整 File Detection 設定，或對個別檔案手動啟用。

需要 C# Dev Kit 或更高版本的 .NET 嗎？

這個工具箱不取代 C# 語言服務，也不強制依賴 C# Dev Kit。基本檔案型命令需要 .NET SDK 10.0.100+；管理專案參考與格式化功能需要 .NET 11+。進階編輯體驗仍由你安裝的 C# 擴充套件提供。

為什麼發佈可執行檔時需要原生工具鏈？

.NET 檔案型應用程式預設使用 Native AOT 發佈。若不需要 AOT，可加入 #:property PublishAot=false 改用架構相依發佈。

可以在遠端工作區或瀏覽器裡使用嗎？

遠端工作區的命令由遠端擴充套件主機執行，因此該環境必須安裝 .NET SDK。純瀏覽器與虛擬工作區不支援這些 CLI 功能；WSL、SSH 與 Dev Containers 仍需實際環境驗證。
